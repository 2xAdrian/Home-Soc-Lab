# Publish this project on GitHub (after attribution and privacy review)

1. Log in to GitHub; choose **New repository**.
2. Suggested repository name: `home-soc-lab`. Add a description such as *Windows SOC lab: Sysmon, Splunk, Atomic Red Team, MITRE ATT&CK and detection tuning*.
3. Set it **Private first** until the authorship question is resolved and screenshots are reviewed. Avoid auto-creating a README; this bundle already provides one.
4. Select **uploading an existing file** and drag in the extracted project files and directories, preserving `assets/`, `docs/`, `detections/`.
5. Commit the files. Check that `README.md` renders and images are visible.
6. Confirm contributors' permissions and choose a license only if appropriate; this draft intentionally includes no LICENSE.
7. If approved for publication, change repository visibility to Public and pin it on your GitHub profile.
8. Add the GitHub repository URL to your resume/portfolio (only once publication is approved).

**Important:** This is a repository of documentation and detection work, not a GitHub Pages web application. The README displays automatically on GitHub.
